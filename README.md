# Agarwal Woodcraft Industries calculators

Upload all three HTML files to the **root** of a new public GitHub repository:

- `index.html` — home page with links to both calculators
- `Wood_Plank_Calculator.html` — table-based plank calculator
- `Agarwal_Raw_Wood_Calculator.html` — table-based raw wood/tree calculator

Then open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.

The site uses relative links, so all three files must remain in the same root folder. Buttons include a short click tone (browser/device audio settings can affect sound). Each page has Wood, Forest, Ocean, and Royal colour themes.
